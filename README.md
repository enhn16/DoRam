# 📚 두람(Duram)

> **부모에게는 아이의 자람을, 아이에게는 성장의 보람을**

부모와 자녀의 역할을 분리하여 아이의 학습 및 생활 습관을 관리하는 개인용 웹 서비스입니다.

---

## 프로젝트 소개

초등학생 시기의 학습 습관은 꾸준한 반복이 중요하지만, 스스로 동기를 유지하기는 어렵습니다. 또한 종이 체크리스트나 메신저를 이용한 수동 관리는 기록 관리와 보상 제공에 불편함이 있습니다.

**두람**은 이러한 문제를 해결하기 위해 만든 **가족 맞춤형 습관 관리 플랫폼**입니다.

보호자는 목표를 등록하고 달성을 확인하며, 아이는 목표를 수행하여 포인트를 모으고 원하는 보상으로 교환합니다.

---

## 프로젝트 목표

* 부모와 자녀가 함께 사용하는 습관 관리 서비스
* 실제 사용자(초등학교 4학년 동생)를 위한 개인 프로젝트
* MVP(Minimum Viable Product) 개발 후 실제 사용 및 개선

---

## 주요 기능

### 👨‍👩‍👧 관리자(보호자)

* 목표 생성 / 수정 / 삭제
* 목표 달성 확인
* 목표 달성 시 포인트 자동 지급
* 달성 메모 작성
* 보상 쿠폰 생성 / 수정 / 삭제
* 쿠폰 사용 완료 처리
* 캘린더를 통한 달성 기록 조회

### 🧒 사용자(아이)

* 목표 확인
* 현재 포인트 확인
* 포인트를 이용한 쿠폰 교환
* 쿠폰함 조회
* 캘린더를 통한 달성 기록 확인

```text
아이가 목표 수행

↓

관리자가 달성 확인

↓

포인트 지급

↓

캘린더 기록

↓

포인트 누적

↓

쿠폰 교환

↓

쿠폰 사용 완료
```

## 프로젝트 목적

이 프로젝트는 상용 서비스를 목표로 하기보다, **실제 사용할 서비스를 직접 기획하고 개발하며 개선하는 과정**에 의미를 두고 있습니다.

개발 후 실제 사용자(동생)의 피드백을 반영하여 기능과 UI를 지속적으로 개선할 예정입니다.
