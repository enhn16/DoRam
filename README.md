# 🍀 두람 (DoRam)

> **부모에게는 아이의 자람을, 아이에게는 성장의 보람을**  
> 보호자와 자녀가 함께 사용하는 다중 가족(Multi-Pair) 습관 관리 웹 서비스입니다.

---

## 📖 프로젝트 소개

초등학생 시기의 학습 및 생활 습관 형성을 돕기 위해 만든 실사용 기반의 습관 관리 서비스입니다.  
초등학교 4학년 동생과의 실사용 경험(MVP)을 바탕으로, 여러 가족이 독립적으로 사용할 수 있는 **다중 페어 서비스**와 **실시간 알림 시스템**으로 확장했습니다.

- **보호자**: 목표 등록, 달성 승인 및 칭찬 피드백, 보상 쿠폰 관리, 실시간 알림 수신
- **아이**: 목표 달성 인증, 포인트 적립 및 출석 연속일수 확인, 보상 쿠폰 교환 및 사용 신청

---

## ✨ 주요 기능

### 👨‍👩‍👧 관리자 (보호자)
- **가족 식별 & 보안**: 가족 코드 및 4자리 관리자 PIN을 통한 안전한 접근
- **목표(미션) 관리**: 일일/주간 목표 생성, 수정, 삭제 및 포인트 설정
- **달성 승인 & 피드백**: 아이의 인증 내역 확인, 승인/반려 처리, 칭찬 한마디 작성 및 포인트 지급
- **보상 쿠폰 관리**: 쿠폰 등록/수정/삭제, 아이의 쿠폰 사용 승인 시 구매 내용 메모(예: 편의점 간식 등) 기록, 사용 완료 내역 조회
- **캘린더 뷰**: 월별 달성 현황 및 히스토리 조회
- **가족 및 알림 설정**: 가족 이름 변경, PIN 재설정, 가족 코드 간편 복사, 원클릭 자동참여 링크(`?family=CODE`) 복사, 스마트폰 푸시 알림 켜기/끄기

### 🧒 사용자 (아이)
- **원클릭 간편 로그인**: 가족 식별 후 클릭 한 번으로 친숙한 아이 화면 즉시 진입
- **목표 수행 & 인증**: 오늘의 목표 체크 및 인증 메모/사진 제출
- **포인트 & 연속 달성**: 보유 포인트 확인 및 매일 출석 연속일수(Streak) 추적
- **쿠폰 교환소**: 모은 포인트로 원하는 보상 쿠폰 교환 (컨페티 축하 효과)
- **내 쿠폰함**: 보유 쿠폰 사용 신청("⏳ 확인 대기중" 상태 지원), 신청 취소, 과거 사용 완료 내역 및 보호자 구매 메모 확인

### 🔔 실시간 알림 시스템
- **스마트폰 백그라운드 푸시 (OneSignal)**: 앱을 꺼두어도 아이의 미션 제출/쿠폰 사용 신청 시 보호자 스마트폰 상단바에 즉시 푸시 알림 전송
- **실시간 인앱 알림 (Supabase Realtime)**: 앱 사용 중 승인 및 제출 발생 시 화면 상단 실시간 토스트 팝업 및 효과음 재생

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 환경 변수 설정 (.env.local 생성)
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_ONESIGNAL_APP_ID=your_onesignal_app_id
ONESIGNAL_REST_API_KEY=your_onesignal_rest_api_key

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 프로덕션 빌드
npm run build
```
